# v3.7.11-g502-f13f16-cn-i18n-sync

Unofficial G502-series fork of Mouser.

Original project: [TomBadash/Mouser](https://github.com/TomBadash/Mouser)  
License: MIT License

## Highlights

- Adds Logitech G502 HERO / G502-series support.
- Adds a G502 visual layout and configurable G502 physical buttons.
- Adds onboard F13-F16 unlock support for G502 DPI/Profile special buttons.
- Saves a G502 onboard backup before modifying onboard memory.
- Localizes the action ring and popup/status messages according to the selected language.
- Provides a Windows GUI executable build that does not open a terminal window.

## G502 onboard mapping

- DPI Shift -> F13
- DPI Down -> F14
- DPI Up -> F15
- Profile Cycle -> F16

## Install

1. Quit any currently running Mouser instance.
2. Download and extract the Windows zip asset.
3. Run Mouser.exe from the extracted folder.
4. Keep the whole extracted folder together; do not run Mouser.exe after moving it away from _internal.
